# binance-alpha

> 币安价格自动计算工具 - 实时采样稳态增强版（Tampermonkey 用户脚本）

## 📌 功能特性

- **分段布局与胶囊开关**：全新设计的悬浮控制面板，支持自由拖拽与折叠收起。
- **一键下单快捷链路**：按住 `Ctrl + Alt` 点击成交记录行，自动读取成交价、计算买入与反向卖出价格并完成自动填充与下单确认。
- **稳态余额采样**：实时监听 USDT 可用余额变动，自动计算并展示本次会话消耗。
- **目标追踪与达标提醒**：支持自定义预设刷分目标（如 32768 / 65536），实时汇总有效成交额与目标差额，达标后自动弹窗提醒。
- **防覆盖保护与容错**：内置防覆盖重试、异常熔断以及 `Esc` 键随时紧急中止保护。

## 🚀 安装方式

1. 安装浏览器扩展（[Tampermonkey](https://www.tampermonkey.net/) 或 [ScriptCat](https://scriptcat.org/)）。
2. 将 `binance-alpha.user.js` 代码复制并添加到用户脚本管理器中。
3. 打开并刷新 [Binance 交易页面](https://www.binance.com/) 即可生效。

## ⌨️ 常用操作与快捷键

- `Ctrl + Alt + 点击成交记录`：一键触发下单流程。
- `Esc`：紧急中断当前正在执行的一键下单动作。
- 点击面板空白区域：自动读取剪贴板价格填入。
